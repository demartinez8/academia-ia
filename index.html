De una idea a un sitio web publicado en Internet, con ayuda de IA

IA aplicada y Automatización con IA es un curso de práctica guiada: aprendes a especificar lo que necesitas, a que la IA lo convierta en código, a validarlo con criterio y a publicarlo con GitHub Pages. Sin instalar programas y sin usar la terminal.

Competencias

Qué aprenderás

El curso no evalúa quién escribe más código. Evalúa que puedas pasar de una necesidad a un prototipo publicado, pedir ayuda técnica con precisión, validar lo generado y explicar tus decisiones.

Especificar antes de programar

Convertir una idea difusa en una especificación clara: objetivo, público, secciones, estilo, acción principal e interacción. Es el paso que decide la calidad del resultado.

Leer y entender el código

Reconocer qué hace el HTML, el CSS y el JavaScript dentro de un único archivo, y saber exactamente qué bloque tocar para cambiar un color, un texto o un comportamiento.

Versionar y publicar

Crear un repositorio, subir tu index.html a la raíz, activar GitHub Pages sobre main + /(root) y obtener una URL pública que se redespliega sola en cada cambio.

Validar con responsabilidad

El código generado por IA puede fallar. Aprendes a leer, probar, modificar poco a poco y validar antes de publicar, y a no exponer nunca credenciales ni datos privados.

Depurar con método

Describir un síntoma con precisión, formular hipótesis, comprobarlas, aplicar la corrección mínima y diseñar una prueba que confirme que el problema quedó resuelto.

Accesibilidad y responsive

Que el sitio funcione con teclado, muestre el foco, tenga contraste suficiente, use alt en las imágenes y se adapte a computador, tableta y móvil.

Paso a paso

La ruta, de la idea a la URL pública

Cada paso produce un entregable verificable. Nada se da por hecho: todo se prueba.

  1. 1

    Define la idea

    Eliges qué sitio quieres construir, con información real que puedas publicar o con un caso ficticio coherente.

  2. 2

    Deja que la IA te entreviste

    En lugar de pedir «hazme una página», pides que te pregunte una por una sobre nombre, objetivo, público, secciones, estilo y acción principal.

  3. 3

    Confirma la especificación

    La IA resume tu proyecto, tú corriges los errores y solo entonces autorizas la generación del código.

  4. 4

    Genera un único index.html

    HTML semántico, CSS en <style> y JavaScript en <script>, dentro del mismo archivo, sin frameworks ni backend.

  5. 5

    Sube el archivo a GitHub

    Creas un repositorio público, añades index.html en la raíz y registras el cambio con un mensaje de commit claro.

  6. 6

    Activa GitHub Pages

    En Settings → Pages seleccionas la rama main y la carpeta /(root), y guardas.

  7. 7

    Prueba tu URL pública

    Recorres el menú, los botones, el formulario, la interacción y la versión móvil. Si algo falla, documentas el síntoma antes de tocar nada.

  8. 8

    Mejora una interacción

    Eliges una sola mejora, pides un cambio acotado, lo aplicas con un commit y esperas el nuevo despliegue.

  9. 9

    Explica tus decisiones

    Documentas la especificación, los prompts, la prueba realizada, un error encontrado y qué aprendiste del código.

Cómo trabajamos

Metodología: Code, No-Code, Low-Code e IA

La IA reduce la barrera de entrada al Code: tú describes lo que necesitas y la IA propone una implementación. Pero la decisión y la validación siguen siendo tuyas.

No-Code

Construir sin escribir código

Herramientas que permiten armar un producto con poca o ninguna escritura manual de código.

Low-Code

Visual más pequeños ajustes

Combina constructores visuales con pequeñas cantidades de código para resolver lo que la herramienta no cubre.

Code

Control total

Trabajo directo con HTML, CSS y JavaScript. Máxima libertad y, también, máxima responsabilidad.

Code + IA

La vía del curso

Especificas con precisión, la IA redacta el código, tú lo lees, lo pruebas y lo corriges antes de publicar.

Principio de responsabilidad del curso: el código generado por IA puede fallar. No publiques a ciegas. Lee, prueba, modifica poco a poco y valida. Nunca pegues contraseñas, tokens, claves de API ni datos privados en un repositorio público.
